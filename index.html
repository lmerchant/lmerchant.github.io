Project pages

Data projects published on GitHub Pages: tools for finding and assessing precipitation datasets, and a map of ocean data.

Precipitation data

  • R* Scores for precipitation datasets

    How likely each dataset is to stop being available, scored from web research. Read the evidence for each part of the score and choose your own scores.

    Source on GitHub for R* Scores

  • Precipitation Workshop Dashboard

    Gauge, satellite, reanalysis and merged precipitation products, with their archives, coverage, resolution and record status. Search and filter by data source and coverage.

    Source on GitHub for the Precipitation Workshop Dashboard

  • US precipitation data sources dashboard

    US data centers, systems and research projects that hold precipitation data, from NASA, NOAA, NSF, NWS and others, with their holdings and data endpoints. Filter by agency and topic.

    Source on GitHub for the US precipitation data sources dashboard

Ocean data

  • Colocation map of CCHDO and BCO-DMO

    A map of where CCHDO bottle and CTD data and BCO-DMO CTD data were collected, to see where the two archives' data overlap.

    Source on GitHub for the colocation map
